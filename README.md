# Zonkey キーマップ工房

自作キーボード **Zonkey**（ZMK ファームウェア）のキーマップを、日本語で編集・テストできるブラウザアプリです。
インストール不要。ブラウザだけで動き、ビルド手順もありません。

## できること

| 画面 | 内容 |
| --- | --- |
| ✏️ 編集 | Zonkey の実際の配列（トラックボール・親指キーの角度込み）でキーをクリックして編集。キーは日本語のカテゴリ・検索・「PC のキーを押して指定」で選べます。ドラッグで入れ替え、元に戻す／やり直す、コピー＆貼り付け、レイヤーの追加・名前変更も可能。 |
| 🧪 シミュレーター | 書き込む前に、キーを押すと PC に何が届くかを確認。レイヤー切替、タップ／長押し（`lt` `mt` と自作 hold-tap、flavor・判定時間も再現）、Shift で変わるキー（mod-morph）、マクロ、ワンショット、自動マウスレイヤーに対応。PC のキーボードやタッチでの同時押しもできます。 |
| 🔌 実機テスト | ファームを書き込んだ Zonkey を接続してキーを押すと、届いたキーに ✓ が付きます。レイヤーごとに「全キー確認できたか」がわかります。 |
| 📄 コードとチェック | 書き出される `.keymap` を確認・コピー・ダウンロード。存在しないレイヤーの参照、未定義の動作、使われないレイヤー、戻れなくなる固定レイヤーなどを自動チェック。 |

### JIS 配列の PC で使う人向けの工夫

ZMK のキー名は US 配列が基準なので、JIS の PC では刻印と違う文字が出ることがあります（例: `&kp AT` → `"`、`&kp LBKT` → `@`）。
このアプリはキーボード上の表示を **「JIS の PC で実際に出る文字」** にしています。
キー選択の「記号（JIS で出したい文字）」タブで `@` を選ぶと、自動で `&kp LEFT_BRACKET` が入ります。
ヘッダーの「PC の配列」を US に切り替えることもできます。

## 使い方

1. 公開 URL（下記）を開く。初回は Zonkey 公式（kureyakey/zmk-config-zonkey）のキーマップが表示されます。
2. 「📂 読み込み」→「GitHub から」で自分の `zmk-config-zonkey` を指定して読み込み。
3. 編集・シミュレーターで確認。
4. 「💾 保存」→「GitHub にコミット」。GitHub Actions でファームウェアのビルドが始まります。
   完了したら Actions の Artifacts から firmware をダウンロードして Zonkey に書き込み、「🔌 実機テスト」で確認します。

GitHub への保存には Fine-grained personal access token（対象リポジトリのみ、`Contents: Read and write`）が必要です。
トークンはブラウザ内でのみ使い、GitHub 以外には送りません（「記憶する」をオンにした場合のみブラウザに保存）。
トークンを使わない場合は、ダウンロードした `.keymap` を `config/zonkey.keymap` として手動でアップロードしても同じです。

編集中の内容はブラウザに自動保存されるので、閉じても続きから再開できます。

## 公開方法（GitHub Pages）

リポジトリの Settings → Pages で「Deploy from a branch」を選び、このブランチの `/ (root)` を指定してください。

## ローカルで動かす

```sh
npm start        # http://localhost:8000 を開く（python3 が必要）
npm test         # パーサー・シミュレーター・チェックのテスト
```

## 制限事項

- 書き換えるのはレイヤーの `bindings` / `display-name` / `sensor-bindings` だけです。コメント・`#define`・behaviors・combos などはそのまま残します（behaviors の中身の編集は「コードとチェック」でテキストを直接編集）。
- レイヤーの削除は番号がずれないよう最後のレイヤーのみ可能です。
- シミュレーターは ZMK の動きを簡略化したものです（combos、`require-prior-idle-ms` などは未対応）。
- 実機テストは PC に届くキーで判定するため、レイヤー切替・Bluetooth・マウスボタンなどのキーは対象外です。Win キーなど OS が先に処理するキーは届かないことがあります。
- 物理配列は公式の `config/zonkey.json` に合わせています。トラックボールの位置は目安です。
